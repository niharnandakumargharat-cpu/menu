# 📖 Mobile-First Digital Menu Website (QR & NFC Ready)

A fast, smartphone-optimized **Digital Menu Website** for restaurants and cafes. Customers can scan a table QR code or tap an NFC tag with their phone to instantly browse your dishes, prices, and descriptions with zero downloads or ordering hassle.

---

## ✨ Features

- **Mobile Website Design**: Fits 100% on any smartphone (Android / iOS) with native touch smoothness.
- **2 Viewing Modes**:
  - 🖼️ **Photo Cards View**: Large food photos, tags, and detailed descriptions.
  - 📄 **Compact Menu List View**: Classic cafe paper-style layout for fast scanning.
- **Sticky Category Pill Bar**: Smooth horizontal scrolling with automatic scroll-spy.
- **Dietary Indicators**: Standard Indian 🟢 **Pure Veg** and 🔴 **Non-Veg** markers on every dish.
- **Live Search & Filter**: Real-time search by dish or ingredient, plus filters for *Veg Only*, *Non-Veg*, *Bestsellers*, and *Under ₹100*.
- **Add-on Notes**: Clear notes on items for *Extra Cheese (+₹20)*, *With Ice-cream (+₹20)*.
- **Customer Utilities**:
  - 📞 **Call Counter**: 1-tap phone dialer for questions or table service.
  - 📶 **Free Wi-Fi Card**: Displays cafe SSID and password with 1-tap copy.
  - ↗️ **Share Menu Link**: Native mobile share sheet or copy link.
  - 🌙 **Dark / Light Mode**: For dim ambient cafe lighting or bright daytime sunlight.
- **Table QR Code Stand Generator (`tables-qr.html`)**: Built-in generator to print tabletop tent cards for Tables 1 through 20.

## 🌐 How to Host Online (Free)

This is a lightweight static website that runs anywhere:

1. **GitHub Pages (Free)**:
   - Create a repo on GitHub, push these files, and turn on GitHub Pages in Repository Settings.
   - Your link will be: `https://<your-username>.github.io/<repo-name>/`

2. **Vercel / Netlify / Cloudflare Pages**:
   - Drag and drop this folder on [Vercel](https://vercel.com) or [Netlify](https://netlify.com) for instant live HTTPS hosting.
